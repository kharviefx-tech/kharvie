UPLOAD MEDIA

Choose photos directly from your phone storage or computer. Upload them to the Kharvie media library.

On Android/iPhone, this opens your phone's Photos/Files picker. On computer, it opens your normal file browser.
How it works

For Gallery photos, the uploader can add the uploaded image to the Gallery table automatically. For covers and other images, the secure public image URL is shown with a Copy URL button so you can paste it into Song or Release → Cover Image URL.
