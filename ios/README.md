# iOS store target

This directory is the reserved native iOS target for the Kharvie Capacitor app.

Generate the native project once on macOS with:

`npx cap add ios`

Then sync web assets with:

`npx cap sync ios`

Open the project with:

`npx cap open ios`

Configure the Apple Developer Team, signing, bundle identifier `com.kharvie.music`, capabilities and App Store Connect distribution in Xcode before archiving and uploading.
